Nápověda — Vývojové diagramy

1. Ovládání a Klávesové Zkratky

  • Přidat blok: Kliknutí nebo přetažení myší z levého panelu na plátno.
  • Přesun bloku: Stiskněte levé tlačítko myši na bloku a táhněte.
  • Editovat text: Dvojklik na blok (Operace, Podmínka, Komentář).
  • Propojení bloků: Táhněte z výstupního bodu (kolečka) na okraji jednoho bloku a pusťte kdekoli na druhém bloku. Tažením z již zapojeného bodu spoj přepojíte.
  • Změna True/False větví: Označte blok Podmínky a klikněte na tlačítko nad ním. Už připojené spoje se přesunou s větví, takže význam True/False zůstane zachován.
  • Zlomový bod spoje: Dvojklik na spoj přidá bod, který lze táhnout (tlačítko Edit path).
  • Výběr více prvků: Tažením vytvořte výběrový rámeček nebo držením Shift + klik.
  • Posun plátna (Pan): Pravé tlačítko myši + tažení po plátně.
  • Přiblížení/Oddálení (Zoom): Kolečko myši nebo tlačítka v horní liště.
Klávesové zkratky:
Ctrl + C / Cmd + C — Kopírovat vybrané bloky (i se spoji mezi nimi)
Ctrl + X / Cmd + X — Vyjmout vybrané bloky
Ctrl + V / Cmd + V — Vložit zkopírované bloky na pozici kurzoru
Ctrl + A / Cmd + A — Označit vše
Ctrl + Z / Cmd + Z — Zpět (Undo)
Delete / Backspace — Odstranit všechna označená data (bloky i čáry naráz)
Esc — Zavřít editor textu / Zavřít nápovědu

2. Základní Práce a Proměnné

Přiřazení hodnoty: x = 5 · text = "Ahoj svet"
Aritmetické výrazy: y = x + 10 · z = (x + y) * 2
Inkrementace / Dekrementace: x++ (přičte 1) · x-- (odečte 1)
Složené přiřazení: x += 5 · x -= 2 · x *= 3 · x /= 2 · x %= 3
Náhodné číslo: x = random(1, 6) (celé číslo od 1 do 6)
Více příkazů v 1 bloku: Oddělujte středníkem ;
Příklad: x = 10; y = 20; print(x + y)

3. Vstup a Výpis (Konzole)

Výpis na konzoli: print(x) nebo write(x) · více hodnot oddělte čárkou print("x =", x)
Spojení textu a proměnné: print("Vysledek je: " + x)
Načtení vstupu od uživatele: x = read()
Načtení přímo do prvku pole: a[i] = read()

4. Aritmetika a Modulo (%)

Základní operátory: + (sčítání / spojení), - (odčítání), * (násobení), / (celočíselné dělení)
Dělení / je vždy celočíselné: výsledek je celé číslo, desetinná část se zahodí (zaokrouhlení k nule).
Příklad: 7 / 2 → 3 · -7 / 2 → -3 · 7 % 2 → 1
Dělení nulou zastaví program s chybou.
Modulo (zbytek po celočíselném dělení): %
Příklad: 10 % 3 → výsledek je 1
Test sudosti čísla: x % 2 == 0 (vrátí true pro sudé číslo)
Test dělitelnosti 5: x % 5 == 0

5. Podmínky a Logické Operátory

Porovnání: == (rovná se), != (nerovná se), <, >, <=, >=
Logický AND (A zároveň): && — platí obě podmínky
Příklad: x >= 10 && x <= 20 (číslo x je v rozmezí 10 až 20)
Logický OR (Nebo): || — platí alespoň jedna podmínka
Příklad: x == 0 || y == 0 (alespoň jedna proměnná je 0)
Logický NOT (Negace): ! — obrátí pravdivost
Příklad: !(x > 5)
Pozor: v podmínce se porovnává ==, jedno = je přiřazení a program ho ohlásí jako chybu.

6. Práce s Polem (Array)

Vytvoření pole (velikost): a = array[10] (vytvoří pole o 10 prvcích)
Přímá inicializace: a = {1, 2, 3, 4, 5} nebo a = {10; 20; 30}
Generování náhodných čísel: a = random(-10, 10) (naplní existující pole čísly od -10 do 10)
Práce s prvky: a[0] = 5 · a[i] = read() · a[i]++ · a[i] += 2
Délka pole: a.length (např. v podmínce cyklu i < a.length)

7. Chyby, ukládání a export

Chyby: neznámý příkaz, nedefinovaná proměnná, index mimo pole nebo dělení nulou program zastaví. Chybný blok se zbarví červeně a v konzoli je popis chyby.
Nezapojené bloky: když z bloku nevede spoj (nebo podmínce chybí větev), program skončí s upozorněním, že nedošel do bloku Stop.
Zacyklení: po 10 000 krocích se běh zastaví — nejspíš jde o nekonečnou smyčku.
Automatické ukládání: diagram se průběžně ukládá v prohlížeči a po obnovení stránky se vrátí. Čistou plochu založí Nový diagram.
ID a otisk: každý diagram má trvalé ID (vzniká při založení a zůstává i po exportu a importu) a otisk — kontrolní součet SHA-256 z obsahu. Jakákoli změna diagramu změní otisk. Obojí je vidět v levém panelu, v názvu exportovaného souboru, v XML (atributy id a hash) a v PNG (patička obrázku a metadata). Při importu XML editor otisk ověří a upozorní, pokud byl soubor upraven mimo editor.

8. Ukázkové Příklady Algoritmu

Příklad 1: Kontrola sudosti
1. Operace: x = read()
2. Podmínka: x % 2 == 0
3. True větev: print("Sude") | False větev: print("Liche")

Příklad 2: Naplnění a výpis pole v cyklu
1. Operace: a = array[5]; i = 0
2. Podmínka: i < a.length
3. True větev (Operace): a[i] = (i + 1) * 10; i++ (zpět na podmínku)
4. False větev (Operace): print(a)
