Pravidla a selektory, box model, rozložení pomocí Flexboxu a Gridu, přechody a animace

Zpět

Co je CSS

CSS (Cascading Style Sheets, kaskádové styly) je jazyk, který říká, jak mají elementy HTML vypadat: barvy, písmo, velikosti, odstupy, rozložení na stránce i pohyb. HTML určuje, co na stránce je, CSS určuje, jak to vypadá.

Díky oddělení obsahu a vzhledu stačí jeden soubor stylů pro celý web: změníš barvu na jednom místě a změní se na všech stránkách. Stejné HTML může mít úplně jiný vzhled na monitoru, na mobilu i při tisku.

Barvy

        
Barvu lze zapsat několika způsoby — všechny níže znamenají totéž. Nejčastější je šestnáctkový zápis #RRGGBB (dvě šestnáctkové číslice na každou složku, viz Číselné soustavy). Zápis hsl() je nejpřirozenější pro člověka: odstín na barevném kruhu, sytost a světlost.

        

            

                

                

                

                

                

            

            

                

                

                
Kromě toho zná CSS 148 pojmenovaných barev (red, navy, tomato, rebeccapurple…) a klíčová slova transparent a currentColor (barva textu).

Box model

        
Pro CSS je každý element obdélník — krabice. Skládá se ze čtyř vrstev: obsah, vnitřní okraj (padding), rámeček (border) a vnější okraj (margin). Pochopit box model je základ pro jakékoli rozložení stránky.

Jednotky délky

        
Velikosti se dají zadat absolutně v pixelech, nebo relativně vůči něčemu jinému. Relativní jednotky jsou základ webu, který se přizpůsobí velikosti displeje i nastavení písma uživatele. Měň hodnoty a sleduj, jak dlouhé budou pruhy.

        

            

                

                

                

                

            

            

                

                
Pruhy jsou zmenšené tak, aby se vešly; hodnota vpravo je skutečná šířka v pixelech.

Kaskáda a specificita

        
Na jeden element se často vztahuje víc pravidel, která si odporují. Prohlížeč pak rozhoduje podle kaskády — v tomto pořadí:

        
    
            
  1. Důležitost — deklarace s !important vyhraje nad ostatními (používej výjimečně).
    2. 
            
  2. Atribut style — styl přímo v elementu přebije pravidla ze stylů.
    3. 
            
  3. Specificita — konkrétnější selektor vyhraje. Počítá se jako trojice (id, třídy, typy) a porovnává se zleva: jedno id přebije libovolný počet tříd.
    4. 
            
  4. Pořadí — při shodě vyhraje pravidlo, které je v kódu později.
    5. 
        

        
Zapínej a vypínej pravidla a přidávej !important. Odstavec v náhledu je obarvený skutečným prohlížečem, takže výsledek vždy odpovídá pravdě.

Dědičnost

        
Některé vlastnosti se z rodiče dědí na potomky: když nastavíš color nebo font-family na body, převezme je celý text stránky. Jiné vlastnosti (border, padding, background, width) se nedědí — rámeček rodiče přece nechceš kolem každého odstavce.

        

            

                
Dědí seNedědí se

                
                
color, font-*, line-height, text-align, letter-spacing, list-style, visibility, cursormargin, padding, border, background, width, height, display, position, box-shadow

                
            

        

        
Dědění můžeš vynutit hodnotou inherit a vrátit vlastnost na výchozí hodnotu pomocí initial.

    


    
    

        
Flexbox

        
Flexbox rozmísťuje prvky v jedné řadě — vedle sebe nebo pod sebou. Hodí se na menu, lišty, zarovnání na střed, řady karet. Nastavuje se na rodiči display: flex, jeho přímí potomci se stanou flex položkami.

        
Flexbox pracuje se dvěma osami: hlavní osa vede ve směru flex-direction, příčná osa je na ni kolmá. justify-content zarovnává podél hlavní osy, align-items podél příčné.

Grid

        
Grid (mřížka) rozmísťuje prvky ve dvou rozměrech najednou — do řádků i sloupců. Hodí se na rozložení celé stránky, galerie a formuláře. Nastavuje se na rodiči display: grid a určením sloupců a řádků.

        
Fialová čísla v náhledu jsou čísla čar mřížky. Položku pak můžeš umístit „od čáry do čáry“: grid-column: 1 / 3 zabere sloupce mezi čarou 1 a 3, span 2 znamená „přes dva sloupce“, 1 / -1 přes celou šířku.

Pojmenované oblasti

        
Přehlednější způsob rozvržení stránky: oblasti mřížky pojmenuješ a „nakreslíš“ je textem. Každý řádek v uvozovkách je jeden řádek mřížky, každé slovo jedna buňka; tečka znamená prázdnou buňku. Oblast se stejným jménem musí tvořit obdélník.

        

        

            

                

                

                

                

            

            

                

                
Každý blok má grid-area se svým jménem, např. header { grid-area: hlavicka; }. Na mobilu stačí v @media přepsat jen grid-template-areas — vyzkoušej předvolbu Mobil.

Transformace

        
Vlastnost transform element posune, otočí, zvětší nebo zkosí. Neovlivní ostatní prvky — stránka se kolem něj nepřeskupí, element se jen jinak vykreslí (přerušovaný rámeček ukazuje jeho původní místo). Proto jsou transformace ideální pro pohyb.

        

            

                

                

                

                

                

                

                
            

            

                
CSS

                

                
Na pořadí funkcí záleží: rotate(45deg) translateX(100px) posune element ve směru, kam už je natočený.

            

        


        
Přechody

        
Když se hodnota vlastnosti změní (třeba při najetí myší díky :hover), změní se normálně okamžitě. transition řekne prohlížeči, ať změnu plynule rozloží v čase. Přechod potřebuje dva stavy — začátek a konec — a spouštěč (změnu stavu).

Plynule lze měnit jen vlastnosti s číselnou hodnotou (délky, barvy, průhlednost, transformace). Přechod mezi display: none a block nebo mezi height: 0 a auto klasicky nefunguje. Nejplynulejší jsou transform a opacity, protože prohlížeč nemusí znovu počítat rozložení stránky.
